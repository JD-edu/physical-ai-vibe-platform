# Python판 실행 방법

아래 명령은 Linux에서 저장소 최상위 폴더를 기준으로 적었습니다.

```bash
cd /home/jdedu/physical-ai-vibe-platform
```

Python 3.10–3.12를 사용하세요. 현재 검증 환경은 Python 3.12입니다. Windows에서는 환경에 따라 `python3` 대신 `python` 또는 `py`를 사용하고 가상환경 활성화는 `.venv\Scripts\activate`로 수행합니다.

## 1. 설치 없이 핵심 흐름 보기

```bash
python3 python_skiils/start_here.py
```

별도 패키지·LLM·카메라·브릿지가 필요하지 않습니다. 준비된 회신 예제를 사용해 앱 구성과 명령 미리보기를 출력합니다.

예상 결과의 일부:

```text
feature-1 camera_stream 카메라
feature-2 control 모터 속도
버튼: 전진 명령: CMD:motor:forward:27
버튼: 정지 명령: CMD:motor:stop:0
```

실제 스킬 목록 보기:

```bash
python3 python_skiils/main.py --list-skills
```

## 2. 의도 JSON으로 실행

```bash
python3 python_skiils/main.py \
  --intent python_skiils/examples/02_camera_remote.json \
  --camera-url http://192.168.0.123/stream \
  --set feature-2=27 \
  --press feature-3
```

이 명령은 실제 LLM을 호출하지 않습니다. 카메라 주소도 설정값으로 넣을 뿐 영상을 열지 않습니다. `--send`를 지정하지 않으면 명령을 출력만 합니다.

이 예제에서 `feature-2`는 모터 슬라이더이고 `feature-3`은 전진 버튼입니다. 다른 앱에서는 ID 순서가 달라질 수 있으므로 출력된 위젯 목록을 먼저 확인하세요.

## 3. 실제 로컬 Qwen에 문의

기존 llama.cpp 서버가 실행 중이어야 합니다. 기본 주소는 `http://127.0.0.1:8080`입니다.

```bash
python3 python_skiils/main.py \
  --prompt-file python_skiils/examples/camera_remote_prompt.txt \
  --camera-url http://192.168.0.123/stream
```

직접 질문하기:

```bash
python3 python_skiils/main.py \
  --prompt "이 카메라와 CNN으로 양품과 불량을 분류하고 결과만 화면에 표시하는 앱을 만들어 주세요." \
  --camera-url http://192.168.0.123/stream
```

다른 주소·모델 사용:

```bash
python3 python_skiils/main.py \
  --llm-url http://127.0.0.1:8080 \
  --model qwen3-8b \
  --prompt "서보 각도를 0부터 180까지 조절하는 슬라이더를 만들어 주세요."
```

`--model`에는 서버가 실제 제공하는 모델 ID를 넣어야 합니다. 모르겠으면 생략하세요. `/v1/models`에서 자동으로 확인합니다. 인자 없이 `python3 python_skiils/main.py`를 실행하면 터미널에서 질문을 입력받습니다.

결과는 기본적으로 `python_skiils/output/`에 저장합니다.

| 파일 | 내용 |
|---|---|
| `prompt.json` | 사용자 질문 |
| `context.json` | 설정한 카메라와 질문에서 명시한 URL |
| `llm_trace.json` | 회신 원문, 시도 횟수, 검증 오류 |
| `intent.json` | 해석한 의도 |
| `project.json` | 최종 앱 구성 |
| `models/` | 화면에서 학습 후 저장한 모델 |

다른 결과와 구분하려면 `--output python_skiils/output/my_robot`처럼 지정합니다. 같은 출력 폴더를 재사용하면 JSON 결과가 갱신됩니다.

## 4. 카메라·화면용 패키지 설치

입문 예제와 LLM 문의·의도 처리에는 표준 라이브러리만 사용합니다. 카메라 화면부터는 다음 설치가 필요합니다.

Ubuntu에서 가상환경과 Tkinter가 없다면:

```bash
sudo apt install python3-venv python3-tk
```

가상환경 만들기:

```bash
python3 -m venv python_skiils/.venv
source python_skiils/.venv/bin/activate
python -m pip install -r python_skiils/requirements.txt
```

이후 예제에서 `python3` 대신 활성화된 가상환경의 `python`을 사용해도 됩니다. 가상환경을 종료하려면 `deactivate`를 입력합니다.

## 5. 카메라와 수동 조종 화면 실행

```bash
python3 python_skiils/main.py \
  --intent python_skiils/examples/02_camera_remote.json \
  --camera-url http://192.168.0.123/stream \
  --gui
```

`192.168.0.123`은 예시입니다. 카메라 OLED나 시리얼에 표시된 실제 IP로 바꾸세요.

화면에서:

1. 오른쪽 카메라 영역에서 주소를 확인합니다.
2. **스트리밍 시작**을 누릅니다.
3. 왼쪽의 속도와 방향 버튼을 조작합니다.
4. 아래 로그에서 생성한 명령을 확인합니다.
5. **스트리밍 종료**를 누르면 수신과 재연결을 중지합니다.

카메라와 조종 버튼을 동시에 볼 수 있습니다. 처음에는 전송 미리보기 모드이므로 모터 명령을 실제로 보내지 않습니다. 카메라만 시험하려면 `examples/01_camera.json`을 사용합니다.

PC 웹캠을 사용하려면 화면의 입력 선택에서 `webcam`을 고르세요. 네트워크 카메라는 `esp32_stream`입니다. 카메라 펌웨어의 단일 스트림 제약을 고려해 기존 에디터 미리보기나 다른 수신 프로그램은 닫고 사용하세요.

## 6. 실제 브릿지로 전송

기존 브릿지 서버와 제어용 ESP32·micro:bit가 연결되어 있어야 합니다. micro:bit에는 해당 명령을 처리하는 프로그램이 별도로 필요합니다.

```bash
python3 python_skiils/main.py \
  --intent python_skiils/examples/02_camera_remote.json \
  --camera-url http://192.168.0.123/stream \
  --bridge-url http://localhost:5000 \
  --gui --send
```

화면의 **브릿지 연결**을 누른 뒤 조종합니다. `--send`는 Python판의 미리보기 대신 실제 HTTP 전송을 허용하는 옵션입니다.

터미널에서 버튼 한 번 실행:

```bash
python3 python_skiils/main.py \
  --intent python_skiils/examples/02_camera_remote.json \
  --set feature-2=27 --press feature-3 \
  --bridge-url http://localhost:5000 --send
```

생성된 앱을 다시 사용하려면 `--project python_skiils/output/project.json`을 지정합니다. 이 경로는 LLM을 다시 호출하지 않습니다.

## 7. 센서·서보·문자 전송

```bash
python3 python_skiils/main.py \
  --intent python_skiils/examples/06_servo_sensor_text.json \
  --gui
```

- 서보 슬라이더 값을 바꾸고 **적용**을 누릅니다.
- 문자 버튼은 `O`를 그대로 전송합니다.
- 센서는 브릿지 연결 후 수신한 데이터를 표시합니다.

지원 수신 형식:

```text
DATA:temperature:24.5
```

또는:

```json
{"type":"sensor","k":"temperature","val":24.5}
```

센서 값이 스스로 생성되는 것은 아닙니다. micro:bit 프로그램에서 실제로 보내는 키와 앱의 키가 일치해야 합니다.

## 8. CNN 설치와 실행

같은 가상환경에서:

```bash
python -m pip install -r python_skiils/requirements-cnn.txt
```

TensorFlow CPU가 포함되므로 설치 용량이 큽니다. GPU는 필수가 아닙니다. macOS에서는 요구 파일이 `tensorflow` 패키지를 선택합니다.

CNN 앱 실행:

```bash
python3 python_skiils/main.py \
  --intent python_skiils/examples/03_classifier.json \
  --camera-url http://192.168.0.123/stream \
  --output python_skiils/output/my_classifier \
  --gui
```

1. 카메라를 시작합니다.
2. 양품 장면을 보여 주고 해당 클래스의 **5장 수집**을 누릅니다.
3. 불량 장면을 보여 주고 해당 클래스의 **5장 수집**을 누릅니다.
4. 클래스별 최소 5장, 권장 20장 이상을 다양한 조건에서 수집합니다.
5. **학습**을 누릅니다. 처음에는 기본 모델 다운로드 시간이 필요합니다.
6. 새로운 장면에서 **한 번 분류** 또는 **연속 분류 시작/종료**를 누릅니다.

학습이 끝나면 출력 폴더의 `models/feature-N/`에 자동 저장합니다. 다음 실행에서 같은 출력 폴더를 사용하면 저장 모델을 복원합니다. 수동으로 **모델 불러오기**를 눌러도 됩니다. 샘플 원본 이미지는 저장하지 않습니다.

**초기화**는 현재 메모리의 샘플과 분류기를 초기화합니다. 마지막 디스크 저장본은 남아 있어 **모델 불러오기**로 복원할 수 있습니다. 클래스별 샘플을 새로 추가하면 다시 학습해야 합니다.

다른 예제:

```bash
# 분류 결과로 모터 방향·속도 명령 생성
python3 python_skiils/main.py --intent python_skiils/examples/04_classifier_motor.json --camera-url http://카메라IP/stream --gui

# PC 웹캠 가위바위보
python3 python_skiils/main.py --intent python_skiils/examples/05_game.json --gui
```

실제 장치 명령이 필요할 때만 `--send`와 브릿지 연결을 사용합니다. 기본 예제는 미리보기입니다.

## 9. 독립 Python 앱 내보내기

터미널에서:

```bash
python3 python_skiils/main.py \
  --project python_skiils/output/my_classifier/project.json \
  --export python_skiils/output/exported_classifier
```

내보낼 폴더는 새 폴더 또는 비어 있는 폴더여야 합니다. 화면의 **앱 내보내기** 버튼으로도 실행할 수 있습니다. 학습을 마친 뒤 내보내면 저장 모델도 복사됩니다.

내보낸 폴더에서:

```bash
cd python_skiils/output/exported_classifier
python3 run_app.py
```

실제 전송:

```bash
python3 run_app.py --bridge-url http://localhost:5000 --send
```

다른 PC로 옮길 때는 내보낸 폴더 전체를 복사하고 그 PC에 Python·Tkinter와 필요한 라이브러리를 설치합니다. PhyVibe 에디터와 로컬 LLM 서버는 필요하지 않습니다. HTML 웹앱이나 설치형 실행파일(EXE)을 생성하는 기능은 아닙니다. 기본 MobileNet 가중치를 처음 사용할 때는 인터넷이 필요합니다.

## 10. 오류를 확인하는 순서

| 증상 | 확인 사항 |
|---|---|
| LLM 연결 실패 | 기존 llama.cpp 서버, 포트, `--llm-url` |
| 회신 검증 실패 | `llm_trace.json`의 원문과 검증 오류 |
| 카메라 연결 실패 | 실제 IP·`/stream`, 같은 LAN, 다른 뷰어 종료 |
| Tkinter 없음 | Ubuntu의 `python3-tk` 설치 |
| 화면을 열 수 없음 | GUI 데스크톱 세션에서 실행, 화면 없이 실행하려면 `--gui` 제외 |
| CNN 설치 필요 | 현재 사용 중인 Python 가상환경과 `requirements-cnn.txt` |
| 클래스 불일치 | 저장 모델의 클래스 순서와 현재 의도 확인, 별도 출력 폴더 사용 |
| 명령이 출력만 됨 | 기본 미리보기 모드, 실제 전송은 `--send`와 브릿지 연결 |
| 명령 전송 성공인데 장치 동작 없음 | 브릿지·제어 ESP32 연결과 micro:bit의 명령 처리 프로그램 |
| 위젯 8개 초과 | 의도에서 요청 기능 수를 줄이기 |

## 11. 검증 명령

기본 처리 흐름:

```bash
python3 -m unittest discover -s python_skiils/tests -p 'test_flow.py' -v
```

같은 의도를 넣었을 때 JavaScript판과 Python판 결과 비교(개발용, 이 검사만 Node 필요):

```bash
python3 python_skiils/tests/compare_javascript.py
```

실제 Python 화면·가짜 카메라·가짜 브릿지:

```bash
python3 python_skiils/tests/check_gui.py
```

실제 CNN 학습·추론·저장·복원:

```bash
python3 python_skiils/tests/check_cnn.py
```

검사는 실제 모터를 조작하지 않습니다. 실제 Qwen 확인은 3절의 문의 명령으로 수행합니다.

화면에서 샘플 수집부터 독립 앱 모델 복원까지 실제 CNN으로 연결해 검사하려면 다음을 실행합니다.

```bash
python3 python_skiils/tests/check_gui.py --cnn
```
